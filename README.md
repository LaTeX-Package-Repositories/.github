# LaTeX Package Repositories

This organisation allows packages that would otherwise fall out of
maintenance be maintained, usually, but not necessarily by LaTeX
Project members. The packages here do not constitute part of the core
LaTeX Project code (which is maintained under the [LaTeX3 github organization](https://github.com/latex3).
